# Access modifiers

Access modifiers tell us wheather we can do use the class,property, method or not.

## Public:

if a class or method is public we can use it from all over the file easily.
but if it is not public the other class and methods will not be easily accesable.
To access them we need to create other helper methods like getter setter.

## Privet:

As privet we can easily understand that the class or method will be privet.
so everything under it will be privet and cant be accessable by other methods and classess.
For coading and softwer security need to learn when to use public and privet for data. Else
it can run a security issue and data loss.

## Protected:

Protected is much more protected than privet. its data only
can be used under its chield class.

## Readonly:

This means data can can be read only and data cant be changed or modified.
